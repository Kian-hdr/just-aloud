# Contributing

Thank you for improving Just Aloud.

1. Base work on the repository's default branch.
2. Keep changes focused and preserve the independent namespaces.
3. Never commit API keys, custom voice IDs, user text, local configuration,
   logs, caches, signing files, notarization credentials, or build products.
4. Run `./scripts/verify.sh` before opening a pull request.
5. Update `CHANGES.md` for user-visible behavior and
   `THIRD_PARTY_NOTICES.md` when dependencies change.

Code contributions are submitted under The Unlicense. Do not add third-party
artwork or code unless its license and attribution are documented. Brand assets
remain governed by [`BRAND.md`](BRAND.md).
